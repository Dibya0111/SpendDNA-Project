# SpendDNA-Project
A data analysis project completed in Python using Jupyter Notebook to explore, clean, and analyze transactional spending data. The notebook demonstrates a complete data-analysis workflow, including data preprocessing, handling missing values, date parsing, feature preparation, exploratory data analysis (EDA), and visualization.

## Project Overview
The goal of this project is to analyze spending data and extract meaningful insights that can support business or financial decision-making. The notebook focuses on preparing raw data for analysis and generating visual and statistical observations from the dataset.
